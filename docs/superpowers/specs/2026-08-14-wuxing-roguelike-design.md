# 五行降世 — 幸存者式肉鸽 设计文档

日期：2026-08-14 ｜ 状态：待审 ｜ 基座：Elemental Sandbox（Three.js + Vite + GLSL）

## 0. 一句话

在现有 VFX 沙盒之上做一个**幸存者式肉鸽**：单竞技场、敌潮环伺、简化手动瞄准、
纯局内成长、15 分钟限时生存；技能体系以**五行（金木水火土）**组织，相生出增益
反应与融合魔法，相克出减益与倍率博弈。

## 1. 已确认的核心决策

| 决策点 | 结论 |
|---|---|
| 形态 | 幸存者式（单竞技场，敌人成波涌入） |
| 施放 | 简化手动瞄准：按键即放（沙盒保留两步瞄准）。**线性技能 = 方向朝鼠标、固定满射程；圈技能 = 落点跟鼠标、range 封顶** |
| 敌人形态 | 程序化几何体（InstancedMesh，无外部资产） |
| 成长 | 纯局内（v1 无局外永久成长） |
| 单局 | 限时 15 分钟生存即胜，v1 无 Boss |
| 敌人属性 | 敌人带五行属性（颜色/材质区分），克制 ×1.25 且必挂减益，被克 ×0.8 |
| 反应系统 | v1 做简化版（单印记 + 相生引爆 + 相克减益，共用一套代码） |
| 槽位 | 6 主动槽，run 模式快捷键 **1–6** + T 禁咒 + 空格闪避（沙盒保持 QERFVX+数字双映射不动） |
| 法力 | **轻量法力**：池 100，+4/秒 + 击杀+1；速射/标准档 0 消耗，战术档 30，重炮档 50（v2）；蓝不够不可放，蓝色蒙层区分于 CD 扫掠 |
| 语言 | 中英双语结构：文案进 strings 表，中文默认、英文备用 |
| 音频 | v1 最小音效集（约 10 个关键音，Web Audio） |
| 实现路线 | 游戏与沙盒共存：标题屏选模式，沙盒 = 数值调试台（938 滑杆） |

### 默认值（已通报，未被否决）

- 施法不锁移动（cast 全身动画盖住跑步，位移照常；难看再上分层动画）
- 性能预算：1080p / 60fps / 中端核显；**同屏敌人硬上限 300**，超限回收最远最老的敌人再投放
- 不做局中存档；localStorage 存最佳成绩、累计统计、设置
- 失焦自动暂停
- run 模式镜头锁玩家居中，弱化 autoFrame；**右键拖拽转动方位**（已实装：fixed
  模式下拖拽写 fixedYaw，右键"点击"以 6px 阈值区分、仍取消施法）；沙盒同样生效
- 桌面浏览器优先，v1 无触屏/手柄；部署走现有 GitHub Pages workflow；
  **WebGL2 检测 + 移动端/不支持环境给干净提示页**（不是白屏）
- **首载资产预算 <10MB**：diffuse2.png（现 6MB）等贴图压缩（pngquant/WebP）进计划；
  非默认角色保持按需加载
- 发布前确认 **Meshy 订阅层级的商用授权**（Mixamo/PolyHaven/ZzFX 均无问题）
- 竞技场：现有圆形场地，`roamRadius` 收到 40m；场景设计见 §5.6（五行法阵竞技场）；
  **场内无障碍纯净场**——地形改造是土系技能的专属价值，障碍由玩家创造不由场景预置

## 2. 架构

新增 5 个系统挂进现有 `App` 帧循环，沿用"App 建系统、发上下文、排更新顺序"模式：

```
App
 ├─ RunManager      局状态机（标题→局内→升级中→死亡/胜利）、计时、潮汐/难度表
 ├─ EnemySystem     敌人生成/AI/实例化渲染/属性与印记数据
 ├─ CombatSystem    技能伤害形状 × 敌人命中判定、印记反应、接触伤害
 ├─ PickupSystem    经验宝石与补给道具的掉落/磁吸/拾取
 └─ UpgradeSystem   卡池生成、三选一、融合/残章/禁咒充能
```

**固定步长约束**：游戏逻辑跑固定步长模拟（如 60Hz tick）+ 渲染插值。
单机收益是判定与帧率无关；同时它与可种子化 RNG、逻辑渲染解耦一起，
构成未来锁步联机的全部地基——除这三件已含在架构里的预埋外，
**v1 不为多人写任何投机代码**。

改动的现有文件（集中三处）：

- `AimController`：新增快速施放路径（arm+confirm 一步，朝当前鼠标方向）；两步流程保留给沙盒
- `App`：接线新系统、玩家 HP/无敌帧/闪避、模式切换
- `settings.js`：新增 run / enemies / combat / upgrades / audio 数值块 → 自动获得编辑器滑杆

数据流单向：RunManager 出波次 → EnemySystem 刷怪 → CombatSystem 读技能状态打怪
→ 死怪掉宝石 → PickupSystem 喂经验 → UpgradeSystem 写局内修正层/装载技能 → 技能变强。

**数值分层（防污染铁律）**：`生效值 = settings 基值 × 局内修正层`。
升级/被动/共鸣**只写修正层**，一局结束整层丢弃；编辑器/沙盒/预设**只动基值**；
两界互不污染——沙盒调的是游戏的"出厂数值"，升级堆的是这一局的"临时 buff"，
`check:balance` 与模拟器永远只对基值负责。

**两种暂停**：沙盒暂停 = 冻结效果但可走动观察（现状哲学不变）；
run 模式暂停（三选一/暂停菜单）= **全停**，含走位与施法。

角色系统已实装（`CHARACTERS` 注册表 + 编辑器切换 + 逐角色 `npm run check`），
v1 沿用；"角色本命被动"立牌远期。

## 3. 战斗判定

技能代码几乎不动：`Ability` 基类公开状态（origin/direction/length/u/position/phase）
已完整描述危险区域；`CombatSystem` 每帧按元素查表施加伤害。

| 现有技能 | 伤害形状 | 触发时机 |
|---|---|---|
| 冰枪 | 前锋点扫掠（伤害点跟随 position，每敌每施法一次） | TRAVEL + 短减速 |
| 雷枪 | 同上，前锋更快 | TRAVEL |
| 陨石 | 落点圆爆发 + 地面灼烧 DoT | IMPACT 一次 + FADE tick |
| 光束 | 整线段持续伤害（点到线段距离 < 宽度） | 保持期间 tick |
| 电缚 | 区域圆 DoT + 减速 | 保持期间 tick |
| 冰川冠 | 区域圆爆发 + 强减速 | IMPACT 一次 |
| 火弹 | 已实现（飞行命中即停 + 爆炸 AoE），仅改目标引用 | 不动 |

**命中语义三原则**：

1. **所见即所判**——判定形状与 VFX 足迹同源：驱动视觉宽度/半径的 settings 参数
   就是（或直接派生出）判定参数。冰晶田铺多宽，伤害带就多宽；瞄准圈画多大，
   打击圈就多大（远程圈瞄准的既有哲学推广到一切判定）。
2. **区域内全体命中，永无目标数上限**——平衡靠形状系数压单次伤害，
   不靠"最多命中 N 个"。假人的 `damage()` 本来就是遍历半径内全部目标，契约不变。
3. **弹道二分**——穿透型（金蝉刃/破军贯穿：路径上全体判定）与触发型
   （火弹：首个命中触发，触发效果本身通常又是 AoE）。50 个主动里**真单体只有
   飞石索与寄生种**，其价值在控制/寄生而非伤害；其余全部区域全体命中。

**目标接口**：把训练假人已有的 `hits(point, radius)` / `damage(point, radius, amount)`
抽成通用契约，`ctx.dummies` → `ctx.targets`（沙盒指假人，run 指敌人系统），
增补 `damageOnce(castId, …)`（扫掠去重）与 `slow(…)`。去重集合与 DoT tick
累积都在 CombatSystem，技能类零改动。

### 4.5 升级

- **光环/环绕类主动**（剑域/燃阵/日轮/大地脉动等）：装备即常驻，
  无冷却无施放动作，升级涨数值；伤害预算走 0.7 形状系数

  逐技能的一行质变描述在实施计划阶段随首发 20 个补齐。
  例：冰枪 L3 冰路+50% 宽，L5 双联齐射）
- 被动 Lv1→3：线性数值
- 获取皆为三选一抽卡；抽到已持有 = 升一级

### 4.6 印记与反应（v1 简化版）

技能命中挂本系印记（每敌 1 个，8s）。第二种元素命中查表：

**相生 = 增益反应**（引爆印记，共用"爆发伤害+一个特效字段"）：
木→火 助燃（引爆+范围引燃）｜ 火→土 烧结（引爆+额外经验碎屑）｜
土→金 淬炼（下发金技能必暴击）｜ 金→水 凝露（冰爆溅射减速）｜
水→木 滋养（引爆+玩家回血）

**相克 = 减益**（打到被克属性的敌人：×1.25 且必挂）：
金克木 断枝（移增益+易伤）｜ 木克土 破土（护甲清零）｜ 土克水 淤塞（减速加倍）｜
水克火 熄灭（敌攻-30%）｜ 火克金 熔甲（受暴击伤+50%）。被克方向 ×0.8。

### 4.7 融合魔法（相生合成）

条件：两主动构成相生对且都 ≥Lv4 → 三选一必出金色融合卡。
融合后两技能合一、**腾出一槽**，融合技 Lv1→3。

| 相生对 | 融合魔法 | 双元素特性 |
|---|---|---|
| 木+火 | 业火燎原 | 燃烧藤蔓自行蔓延，击杀处再分叉 |
| 火+土 | 地心火山 | 火山口喷吐岩浆弹，落点留熔岩+击晕 |
| 土+金 | 锋岩星阵 | 金属棱晶阵起落研磨，破甲+暴击 |
| 金+水 | 霜刃洪流 | 冰晶剑潮往返横扫，回程对减速敌必暴 |
| 水+木 | 回春雷泽 | 雷雨沼泽：减速+连锁落雷，玩家入内回血 |

双属性规则：克制判定取对目标更优一系；可引爆两系印记；自身挂印取相生"子"系。
共鸣计数：两系各计 1。

### 4.8 共鸣与轮转

- **共鸣**：同系主动 ≥2 触发该系共鸣（如水：减速效果+50%）；五系各一触发"周天"
  （全属性小增益+反应增强）
- **相生轮转**：按相生顺序 4s 内衔接施法，后者冷却减半

### 4.9 禁咒（T 键大招）

开局第一个主动技能决定本命系，禁咒随之入 T 槽不可换。
**开局形态**：五张卡各系一张（各系首技：新星光束/雷枪/冰枪/火弹/岩刺突贯），
选 1 = 本命系。充能：击杀+1、触发反应+5，满 100 释放；
数值校到**期望每 2–3 分钟一发**。禁咒**无瞄准**：按 T 即时全场生效。金·万剑归宗（全屏处决线）｜ 木·世界树（全场缠绕+回复）｜
水·绝对零度（全场冻 3s）｜ 火·陨星天坠 ｜ 土·天崩（全场晕+抬地形）

## 5. 敌人系统

**3 行为模板 × 5 行皮肤**（代码只有 3 个 AI）：

| 模板 | 特征 |
|---|---|
| 涌兽 swarm | 快、脆、成群冲脸 |
| 磐兽 tank | 慢、厚、接触伤害高 |
| 吐息者 ranged | 保持 8m 吐弹道（可闪避、可被锋芒护体反弹） |

外观程序化，**五行区分走颜色+轮廓双通道**（色弱可达）：基础几何按 3 个行为模板，
五行叠轮廓装饰件——金棱刺 / 木枝杈 / 水圆壳 / 火裂纹发光 / 土方块感——再配五套
材质色板。观感：金=棱晶碎片体、木=枝节傀儡、水=冰壳凝体、火=熔核岩人、
土=岩石巨像。精英 = 放大+发光（掉残章）。Boss 走 Meshy+Mixamo
管线，二版。

渲染：每（行为×行）一个 InstancedMesh，≤300 同屏 = 15 draw call；数据平铺数组
（pos/vel/hp/element/slow/mark/flash）。

AI：追踪 = 朝玩家向量 × 速度 ×(1−减速)；均匀网格软分离；接触伤害后玩家 0.5s
无敌帧。受击反馈：闪白+微击退+池化飘字（超量聚合"×12"）；小怪无血条，
精英/Boss 才有。死亡：按模板碎裂成实例化碎片+本系粒子，掉宝石。

生成：视野外环形刷入；RunManager 按分钟查表（预算/行为配比/五行潮汐权重）。

## 5.5 打击感与反馈

原则：高频反馈全走实例化属性与已有池化系统，300 同屏不掉帧。

**VFX 可读性减档（华丽特效游戏的第一死因是糊屏）**：run 模式默认挂
"战斗可读性预设"——`settings.global` 全套倍率（粒子数/辉光/shader 强度）
整体下调约 30%，沙盒保持满血华丽；渲染铁律：**敌方威胁（弹道/出生预告）
永远绘制在我方特效之上**。

**敌我可读性**：敌方威胁（吐息者弹道、出生预告圈）**一律红/暖色统一标识**——
玩家技能是五行色烟花海，威胁不统一色会被淹没。玩家**脚下淡光圈**常驻
（瞄准指示器的圆环几何复用），人堆里一眼找到自己。准星光标替换系统箭头。

**敌人出生**：刷怪点先出 0.5s 红系聚集圈（预告）+本系色点缀，再冒出——
不许凭空刷脸。

**每次命中**：闪白（每敌 flash 浮点 1→0 / 0.15s，实例属性进 shader）＋
缩放脉冲（1→1.15→1 / 0.12s）＋ 击退（独立冲量通道，指数摩擦；
质量系数：涌兽 1.0 / 吐息者 0.8 / 磐兽 0.25 / 精英 0.1；"沉重"×1.5）＋
池化飘字（暴击金色加大）＋ 命中音（音高 ±15% 抖动，每帧 ≤8 个，
优先级 暴击>击杀>普通）。

**不做全局顿帧**——每秒几十次命中会顿成幻灯片。顿帧只留大事件：
禁咒/融合引爆/精英击杀 → timeScale 0.85 × 0.1s ＋ CameraShake ＋ ScreenFlash
（三者皆现成）。

**减速/冻结**：slowFactor 数据通道；表现 = 冷色染色（与闪白共用实例色通道）＋
shader 摆动速度 ×(1−slow)；冻结（寒彻骨叠满）= 波动归零＋冰壳色＋脚下霜痕
SDF 贴花。淤塞同通道数值加倍。

**玩家受击**：屏幕边缘泛红（ScreenFlash 变体）＋小震屏＋角色闪红＋HP 条抖动；
无敌帧期间角色半透明闪烁。

**死亡（0.3s 内，死亡先读、奖励后读）**：实例化碎裂（每系 ~12 块程序化碎块，
陨石 CPU 碎裂技术复用；并发 ≤40 组）→ 本系粒子 burst（每系一个预设）→
小块本系地面贴花 2s 淡出（GroundDecals 预算池）→ 宝石延迟 0.15s 弧线蹦出。
精英死亡追加微顿帧+震屏+闪光；燎原/余烬等被动挂同一死亡事件。

## 5.6 场景：五行法阵竞技场

设计原则：**场景是潮汐的叙事者**，全程序化零外部资产；有氛围但绝不与技能特效
抢戏——战斗中心区保持低对比素净，装饰密度向边缘递增。仅挂 run 模式，
沙盒环境原样不动（调参需要素背景）。

1. **地面法阵**：素黑地板换程序化五行法阵——SDF 线条蚀刻巨环 + 五方位各一片
   本系符文区，微发光低对比；Ground shader 加一层 SDF。
2. **五座晶碑边界（三合一）**：40m 边缘立五座程序化晶柱（金棱晶/木藤缠/水冰晶/
   火熔岩/土磐石，ProceduralGeometry + archive 材质），碑间淡光弧相连即警戒线；
   **当前潮汐的碑燃亮、下一潮的碑预热闪烁**——装饰、边界、潮汐指示一体。
3. **天光随潮换装**：暗背景 + 低垂雾带 + 缓动程序化极光/星纱，色调随潮汐缓变
   （火暖橙/水冷青/木翠碧/金银白/土土金）。
4. **五套环境粒子**：DustMotes 五个预设随潮切换——火余烬上飘/水落雪/木飞叶流萤/
   金金屑闪烁/土平流沙尘。
5. **战斗装饰战场**：run 模式贴花/裂缝预算上调、淡出拉长——15 分钟后满地
   焦痕霜迹电灼熔缝，战场自己累积历史。
6. **场内无障碍**：全部装饰在边缘带；性能账 = 五座静态碑 + 一层地面 SDF +
   粒子换色，不占敌人预算。

## 5.7 光影设计

底子沿用现有系统（IBL/级联阴影/接触阴影/LightPool/bloom），run 模式的组织规则：

1. **主光随潮换色温**（20s 缓变，与晶碑/雾/粒子同步）：火=暖橙低角度 /
   水=冷青顶光 / 木=翠碧柔和 / 金=银白锐利高对比 / 土=土金低饱和。
2. **动态光预算**：技能光走 LightPool 池上限 8 盏（最老先回收）；
   **敌人零真光**——发光观感全走 emissive+bloom；精英同理；
   禁咒释放可临时借满光池（大场面特权）。
3. **阴影策略**：主角保留全套（CSM+接触阴影，画面锚点）；
   **敌人不投实时阴影**（俯视角价值极低，省约一半渲染负载），
   着地感用实例化脚下暗斑；静态晶碑烘焙。
4. **亮度层级铁律**：敌方弹道/预告的 emissive 强度 > 我方粒子均值，
   bloom 阈值以此校准——红色威胁必须刺出五行色烟花海。
5. **敌人 rim light**：实例材质带轻微 fresnel 边缘光，暗场里怪群轮廓分明。

## 6. 成长与升级池

**宝石**：绿（小怪，价值 1+0.12×分钟，随局程增值）/ 蓝 15+全场吸附（精英）/
金（潮汐雨，每潮共约 150 点）；磁吸半径 2m 起。
**曲线**：升级经验 = 22 × 1.13^级，15 分钟 ≈29 级（模拟实测中位）；
满配需 30+ 张卡 → 永远在取舍。

**流程**：升级即世界暂停 → 三张卡（键盘 1/2/3 或点击）→ 弃权 = 回血 10%。

**卡池**：新主动（有空槽时；已持有系权重 ×2）· 新被动（同权重规则）·
技能升级（权重最高，满级退池）· 融合卡（条件达成必出）· 通用被动（低权重常驻）。
Lv5/10/15 必含稀有+卡。

**残章**：精英必掉本系残章，捡起弹定向三选一（仅该系），不占升级次数。
**新技能即时演示**：三选一选中新主动后，该技能朝最近敌人**免费自动施放一发**——
立刻看到自己拿了什么。
**自动施法**：暂停面板逐技能开关，自动朝最近敌人释放，伤害 ×0.85。

## 8. 数值骨架

**锚 1 手感**：开局涌兽 1 发死；全程同期涌兽 1–2 发；磐兽 4–6 发；精英集火 15–25s；
被围无操作 ~5s 致死。

**锚 2 基准**：冰枪 Lv1 = 伤害 20、冷却 1.2s。
`单次伤害 ≈ 20 × (冷却/1.2) × 形状系数`（形状系数即命中难度的表达）。
形状系数：窄线 1.3 / 宽线 1.0 / 小圈 1.1 / 大圈 0.8 / 自身光环 0.7 / 弹道 1.2 /
持续型按 tick 均摊。

**锚 2.5 冷却档位**：速射 0.8–1.5s（冰枪/雷枪/火弹/连锁闪电）｜
标准 2–4s（陨石/冰川冠/电缚/落石/岩刺突贯/万剑诀/生命绽放/新星光束 3s）｜
战术 6–10s（弑神一闪/寒霜新星/冰晶甲/震地波/石肤）｜
重炮 12–18s（焚天/炎龙啸等，v2 批次）｜ 常驻无 CD（光环环绕）｜ 禁咒充能制。
法力（轻量）：池 100，回复 +4/秒 + 击杀 +1；速射/标准 0 耗，战术 30，重炮 50。
规则：① CD 进伤害公式，档位换单发强度，全档 DPS 期望持平；
② 升级不动 CD——缩减只来自凝神（每级 −6%）/相生轮转（后者减半）/白虹贯日（暴击返 0.5s）；
③ 缩减乘法叠加，**全局上限 40%**；④ 无公共冷却、无施法前摇，判定与动画解耦，点击即结算；
⑤ 理想 build 分布 2 速射+2 标准+1 战术+1 重炮/常驻；开局本命五技全 ≤ 标准档。

**锚 3 敌人**：涌兽 HP = 20×(1+0.16×分钟)，接触 8；吐息者 ×2，弹道 12；
磐兽 ×6，接触 20；精英 ×40，伤害 ×1.5。
**刷怪预算：每分钟 20 + 2.2×分钟²**（前松后陡，终潮 ~450/分）。

**锚 4 咬合**：技能每级 +25%（Lv5≈2.4×）；敌方威胁 = HP +16%/分 × 数量平方增长；
玩家每次升级期望 +10–15% DPS × ~29 次。模拟实测：压力反超 ~8 分钟起，
基线玩家死亡集中在 13–14 分钟——"差一点就过了"有数据背书。

**锚 5 倍率**：克制 1.25 / 被克 0.8 / 反应爆发 = 触发技单发 ×1.5 /
融合 DPS = 两技之和 ×1.2 / 自动施法 0.85。
