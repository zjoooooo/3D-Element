# M6 量产与发布 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** v1 收官：13 个首发新技能（含土系登场——解锁周天/土禁咒/双融合对/castEarth）经 6 个类（3 模板 + 3 特例）落地、战术档法力消费、护盾机制、编辑器通用折叠、资产瘦身、门面三件套、发布回归清单与 v1 标记。

**Architecture:** 新技能 = 数据行（settings 全量参数）× 少数类：`LineSweepSkill / ZoneBurstSkill / OrbitAuraSkill` 三模板吃掉 9 个，`ShieldSkill(×2) / DashStrikeSkill / ChainBoltSkill` 三特例吃掉 4 个；VFX 全部组合既有系统（粒子预设/实例晶体/SDF 贴花/BurstSphere/丝带）按五行染色。战斗侧只新增 `aura` 与 `shield` 两个语义。现有 7 个手写技能一行不动。

**Tech Stack:** 不变；资产处理只用 macOS 自带 `sips`（零新依赖）。

## Global Constraints（含 M1–M5 全部勘误规程）

- 规程①对照真实文件核对锚点（对账清单 Task 1）；规程②新公开逻辑必附会失败断言；规程③settings 与读者同任务
- 修正层铁律；固定 60Hz tick；热路径零分配；沙盒逐帧不变；`death wins the tick`
- 五字段施放不变量（cooldown/`_applySequence`/`autocast`/`fusionMult`/`quenched`）扩为**六**：法力 spend 是施放门（pre-cast gate），不是 ability 字段——门失败则整次施放不发生
- 新技能伤害必须过 **锚2 公式带**（`20 × (冷却/1.2) × 形状系数`，±40% 断言护栏——spec §8 的防手滑条款在本里程碑正式落地）
- 新 UI 文案一律 `t()`；报告中派单授权的选择必须标注 **dispatch-authorized**（M5 流程教训）
- commit 自然句式 + `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`

**计划内裁定**（用户可否决）：
1. **5 个融合专属 VFX → post-v1 backlog**：合成施放已满足 spec 机制与 ×1.2 预算且视觉上是两发全额技能齐放；13 技能才是本里程碑的山。
2. **首发 13 技能名单**（spec §12 v1 名单）：金=万剑诀/剑域/弑神一闪 · 木=连锁闪电/生命绽放 · 水=寒霜新星/冰晶甲 · 火=燃阵/日轮 · 土=岩刺突贯/落石/震地波/石肤。
3. **护盾机制**：`PlayerState.shield` 吸收池（先于 HP 扣），限时衰减；石肤附接触反伤。HP 瓶液面上叠白色护盾带。
4. **战术档法力**（spec 锚2.5）：弑神一闪/寒霜新星/冰晶甲/震地波/石肤 = 30 蓝；其余新技能 0 蓝。

6. **游戏名保持占位"五行降世"**（用户命名权开放，门面用占位名）。
7. **v1 完成后打本地 tag `v1.0`**（用户负责推送）。
