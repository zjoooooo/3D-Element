# M5 包装 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把灰盒穿上正装：五行法阵竞技场与晶碑、光影随潮、暗黑式血蓝玻璃瓶与正式技能条、法力池、五系禁咒、ZzFX 音效、双语 strings、标题屏/暂停菜单/设置、打击感收尾（死亡碎裂/微顿帧/受击泛红/翻滚闪避）、可达性（减闪/性能模式/WebGL 兜底）。

**Architecture:** 表现层全部读状态不写状态（渲染器/HUD/音频是纯消费者）；新 UI 文案一律走 strings 表；场景与光影挂 run 模式开关、沙盒逐帧不变；禁咒与法力是纯逻辑（Node 可测），效果经既有 targets/tuning API 落地，不新建技能类。

**Tech Stack:** 不变 + vendored ZzFX（MIT，单函数）。

## Global Constraints（含 M1–M4 勘误规程）

- 落笔前对照真实文件核对锚点（规程①）；对账清单见 Task 1，对不上即停
- 每个新公开逻辑方法至少一条会失败的断言（规程②）；视觉任务以浏览器逐项清单为验收主体，逻辑内核仍须 headless 断言
- settings 数值与读者同任务落地（规程③）；修正层铁律；固定 60Hz tick；热路径零分配
- 沙盒（无 `#run`）行为逐帧不变；`death wins the tick`；三施放口不变量（cooldown/`_applySequence`/`autocast`/`fusionMult`/`quenched` 五字段每次施放显式写——新增字段同规）
- **新 UI 文案一律 `t(key)` 走 strings 表**（Task 2 之后的任务硬要求）；沙盒编辑器文案暂留英文不迁
- 敌方威胁红系、我方五行色；威胁 emissive > 我方粒子均值（spec §5.7）
- commit 自然句式 + `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`

**计划内裁定**（spec 意图内落地选择，用户可否决）：
1. **禁咒键 = F**：spec 写 T，但 M1 落地的 loadout 第 6 席已占 T（[LMB,RMB,Q,E,R,T]）；F 在 run 模式无席，顺位最优。勘误记 spec 偏离。

3. **禁咒五效果 = 场级数值合成**（全场 slow/damage/斩杀线/多波打击，走既有 targets API + ScreenFlash/CameraShake/BurstSystem 借力），专属华丽 VFX 入 M6 备选池。
4. **`#run` 进入流程改为标题屏**（开始→五选一本命→开局）；`#run=quick` 保留直入旧行为（调试与既有浏览器验收脚本用）。
5. **翻滚闪避仅 sorcerer**（用户提供的 `Stand To Roll.fbx`，53 轨道 sorcerer 骨架）；classic 无剪辑保持瞬移，fallback 语义记录在案。
6. **法力池 M5 建成、消费者 M6 到货**：蓝瓶恒满是本里程碑的正确表现；spend API 就位待战术档技能。
7. 门面三件套/贴图压缩/回归清单 → M6（发布收尾）。
